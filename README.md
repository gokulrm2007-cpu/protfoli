# Gokul M - Personal Developer Portfolio

Clean, lightweight, and modern personal developer portfolio website for **Gokul M** (B.Sc Computer Science Student at VETIAS College).

## Live Demo
- GitHub Pages: https://gokulrm2007-cpu.github.io/protfoli/

## Project Structure
- index.html - Semantic HTML5 markup, OpenGraph and Twitter preview meta tags, and structured portfolio sections.
- styles.css - Pure CSS design tokens, modern typography, responsive layouts (320px, 390px, 768px, 1280px+), and zero horizontal overflow.
- script.js - Lightweight vanilla JavaScript with central SITE configuration for verified contact/social links, mobile drawer navigation, and scroll tracking.
- profile.webp - OpenGraph and social media preview image.
- favicon.svg - Brand monogram favicon.

## Tech Stack
- Languages: HTML5, CSS3, JavaScript (ES6+)
- Build Step: None (Pure Vanilla Web Standards)
- Hosting: GitHub Pages / Netlify
